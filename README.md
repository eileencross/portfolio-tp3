# Portfolio Personal — TP3

Trabajo Práctico N°3 — Repaso Front-End (Bootstrap) & Git Workflow, SEO, Accesibilidad, HTML Semántico.

## Descripción

Portfolio personal maquetado en HTML5 semántico + Bootstrap, con foco en accesibilidad y buenas prácticas de SEO.

## Vistas

1. `index.html` — Home
2. `about.html` — Sobre mí
3. `projects.html` — Listado de proyectos
4. `project-detail.html` — Detalle de un proyecto
5. `skills.html` — Habilidades / stack
6. `experience.html` — Experiencia y estudios
7. `blog.html` — Listado de artículos
8. `blog-post.html` — Artículo individual
9. `contact.html` — Formulario de contacto
10. `404.html` — Página de error

## Estructura del proyecto

```
/
├── css/
├── js/
├── img/
├── index.html
├── about.html
├── ...
└── README.md
```

## Tecnologías

- HTML5 semántico
- Bootstrap 5
- CSS personalizado
- Prettier (formateo de código)
- Lighthouse (auditoría de accesibilidad, SEO y performance)

## Flujo de trabajo (Git)

1. `git init` + estructura de carpetas
2. Rama `feature/maquetacion` para el desarrollo de las vistas
3. Pull Request de `feature/maquetacion` hacia `main`
4. Deploy en GitHub Pages
