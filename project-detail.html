Plataforma de gestión de tareas

Aplicación web para organizar proyectos en tableros estilo Kanban, con autenticación de usuarios y una API REST propia para persistir la información.

Node.js Express PostgreSQL Bootstrap
Ver demo Repositorio

El desafío

El objetivo era construir una herramienta simple para que equipos pequeños organicen tareas sin depender de licencias pagas, priorizando el rendimiento y una interfaz clara.

La solución

Se desarrolló una API REST en Node.js/Express con autenticación mediante JWT, conectada a una base de datos PostgreSQL. El frontend se maquetó con Bootstrap y JavaScript para actualizar el tablero sin recargar la página.

  • Autenticación y sesiones seguras.
  • Tablero Kanban con arrastrar y soltar.
  • Notificaciones de vencimiento de tareas.

Resultado

El proyecto obtuvo una puntuación superior a 90 en las auditorías de Lighthouse (rendimiento, accesibilidad y buenas prácticas).
